# rescue-sim

茅ヶ崎ヘッドランド 救助連携シミュレーター

🔗 https://surf90.github.io/rescue-sim/

要救助者の位置や環境条件を画面上に設定し、チューブ・ボード・IRB・PWC など
複数の救助手段をどう組み合わせて動かすかを検討・共有するためのシミュレータです。
訓練前のブリーフィングや、動きの確認を想定しています。

## 主な機能

- **本部・要救助者の配置** — 地形上に本部と要救助者を置き、想定を組み立てる
- **環境設定** — 季節・天候・風向・風速を設定する
- **シナリオ編集** — 想定を作成・編集し、1x／2x／4x の速度で再生する
- **イベント一覧** — 時系列でのできごとを確認する
- **保存・共有** — シナリオを JSON で書き出し／読み込みする

## 注記

- 本ツールはサーフ90茅ヶ崎ライフセービングクラブの公式なものではありません。
  メンバー個人が開発・管理しています。
- 画面上の挙動は検討用の簡略モデルです。実際の救助判断は、必ず現場の状況と
  指揮系統に従ってください。
